## Problem Statement

- Students learning basic calculus or while practicing problems manually make mistakes while differentiating expressions/functions.
- This project provide students to verify their solutions instantly and gives clear, step-by-step solution.
 
## Scope

- The variable and angle inputs are limited to single variable terms. 
- This project doesn't give output for multivariable or inner powers or negative variable inside trigonometry and logarithmic functions (eg.sin(x^2)or -x inside any function).
- This project supports following functions:
1. Algebraic function [f(x) = b.x^n]
2. Trigonometric function [f(x) = b.[trigo(x)]^n]
3. Logarithmic function [f(x) = b.[log(x)]^n]
4. Constant function f(x) = k


## Target Users

- First year engineering students
- Senior secondary students learning basic calculus for the first time.
